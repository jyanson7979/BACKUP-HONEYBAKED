🍰 Honeybaked Menu Database Initializer

This tool will set up your menu data on JSONBin.io for both Shop and Custom Cakes pages.

Get your key from jsonbin.io → Account → API Keys

📊 Menu Statistics

📋 Instructions

  1. Get your JSONBin Master Key from jsonbin.io (sign up for free)
  2. Paste your Master Key in the field above
  3. Click "Initialize Both Bins" to create/update your menus
  4. Copy the Bin IDs shown after successful initialization
  5. Update your HTML files with these Bin IDs:
    • Shop Page (orders.html): Change const API = '/api/menu'; to your JSONBin URL
    • Custom Cakes Page: Change the API URL similarly

🔗 API URL Format:

https://api.jsonbin.io/v3/b/[YOUR_BIN_ID]/latest

Headers required:
X-Master-Key: your_master_key
X-Bin-Version: 2 (optional)
